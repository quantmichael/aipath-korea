# AI PATH KOREA 수집 대상 후보

마지막 확인일: 2026-08-19

## 수집 원칙

- 공식 출처를 우선 등록한다.
- 민간 모음 플랫폼은 발견용으로 사용하고, 등록 전 주최사 원문 URL을 확인한다.
- robots.txt, 이용약관, 저작권 정책을 확인한 뒤 자동 수집 범위를 정한다.
- 원문 전체를 복제하지 않고, 서비스에 필요한 제목, 요약, 일정, 대상, 참가 방식, 공식 URL만 정리한다.
- 일정과 조건은 바뀔 수 있으므로 `last_verified_at`을 반드시 갱신한다.

## 수집 필드 매핑

| 원문 정보 | DB 필드 |
| --- | --- |
| 출처명 | `sources.name` |
| 원문 URL | `opportunities.official_url` |
| 외부 게시글 ID 또는 URL slug | `opportunities.external_id` |
| 제목 | `opportunities.title` |
| 요약 | `opportunities.summary` |
| 상세 설명 | `opportunities.description` |
| 주최기관 | `opportunities.organizer` |
| 대상 | `opportunities.target_audience` |
| 카테고리 | `opportunities.category_id` |
| 난이도 | `opportunities.difficulty` |
| 참여 방식 | `opportunities.format` |
| 지역/장소 | `opportunities.region`, `opportunities.venue` |
| 참가비 | `opportunities.price_type`, `opportunities.price_text` |
| 모집 시작/마감 | `opportunities.application_start_at`, `opportunities.application_deadline_at` |
| 행사 시작/종료 | `opportunities.event_start_at`, `opportunities.event_end_at` |
| 상태 | `opportunities.status` |
| 마지막 확인 | `opportunities.last_verified_at` |

## 운영 단계

1. 1차 후보 사이트에서 AI 관련 새 공고를 찾는다.
2. 공식 URL, 일정, 대상, 참가 방식, 비용을 확인한다.
3. 민간 플랫폼에서 발견한 정보는 주최사 원문 URL을 다시 찾는다.
4. 중복 여부를 `source_id + external_id` 또는 `official_url` 기준으로 확인한다.
5. Supabase에 `draft`로 등록한 뒤 사람이 검수한다.
6. 검수 완료 후 `scheduled`, `open`, `ongoing` 중 하나로 공개한다.
7. 마감일 이후 `closed` 또는 `ended`로 상태를 갱신한다.

## 자동화 후보

- 1단계: 주 2회 수동 검색 후 DB 등록
- 2단계: 공식 목록 페이지 HTML 파싱으로 후보 URL만 자동 수집
- 3단계: 상세 페이지에서 일정/주최/대상 필드 자동 추출
- 4단계: 관리자 검수 화면에서 승인 후 공개
- 5단계: 중복 탐지, 마감 상태 갱신, 변경 감지 알림 자동화

## 주의사항

- 자동 수집 전 각 사이트의 robots.txt와 이용약관을 확인한다.
- AI 요약은 원문을 대체하지 않으며, 공식 페이지 링크를 항상 함께 제공한다.
- 이미지와 원문 본문은 권리 확인 전 복제하지 않는다.
- 수집 실패, 파싱 실패, 일정 누락은 공개 전 검수 대상으로 남긴다.

# AI PATH KOREA 서비스 기획서

## 서비스 목적

AI와 여러 산업이 결합되는 환경에서 사용자가 자신에게 필요한 학습·도전·네트워킹 기회를 발견하도록 돕습니다.

## 핵심 사용자

AI를 학습하거나 업무·진로에 접목하려는 입문자와 성장 단계의 사용자입니다.

## 초기 기회 유형

- 교육
- 공모전
- 해커톤
- 밋업
- 콘퍼런스
- 웨비나
- 성장 프로그램

## 핵심 사용자 흐름

사용자는 검색·필터 또는 DB 기반 AI 추천으로 기회를 찾고, 상세 정보와 출처를 확인한 뒤 공식 페이지로 이동합니다.

## 데이터 운영 원칙

- 관리자 큐레이션과 이용 가능한 공식 API를 혼합합니다.
- MVP는 검증된 정보 약 20~30개로 시작합니다.
- 모집 마감일과 실제 행사 개최일을 별도로 관리합니다.
- 출처, 이용조건, 마지막 확인 시각을 기록합니다.
- 일정 변경 가능성을 알리고 최종 확인은 공식 원문에서 하도록 안내합니다.

## AI 기능 기준

- 입력: 수준, 관심 분야, 목적, 참여 방식, 비용, 가능한 기간
- 출력: 최대 3개의 실제 기회와 추천 이유
- 실패 처리: 빈 입력, 검색 결과 없음, API 오류 또는 지연
- 제한: DB에 없는 기회를 생성하거나 지원 자격·선정 가능성을 보장하지 않음
